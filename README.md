# دفتر TARGET COINS

دفتر لمتجر **TARGET COINS STORE**: بتسجل فيه طلبات الشحن، والديون اللي عليك، وأسماء الزباين والتجار و MOHPTON TEAM.

- الرابط اللي بتستخدمه: https://claude.ai/artifact/RumRrdGpJ8Ug1Nrg3YZp2i
- الكود كله بملف واحد: `index.html` (HTML و CSS و JavaScript، من غير مكتبات).

## الأقسام
- **بدي من الناس** (`orders`): قيود الزباين والتجار اللي لازم يدفعولك: الخدمة، المبلغ (₪ / $ / جنيه)، التاريخ، موعد الدفع، تم / لسى.
- **بدهم مني** (`debts`): اللي أنت لازم تدفعلهم. بنموذج التسجيل في زرين «بدي منه» و«بدو مني» بتختار منهم.
- **الأسماء**: زبون عادي / تاجر / MOHPTON TEAM مع رقم الواتس، ولكل اسم جرد صافي (بدك منه أو بدو منك). وفوق في مربع «الجرد الصافي» للكل.
- **الاستلامات**: كل مرة استلمت مصاري (دفعة جزئية من زر «استلمت دفعة»، أو المبلغ كامل لما تكبس «تم»)، مع الاسم والقائمة والتاريخ. الدفعات محفوظة بحقل `payments` بكل قيد بـ `orders`.
- **الجرد الصافي** فوق = اللي انقبض ناقص كل اللي عليك للناس، وتحته قديش بيصير إذا الكل دفعلك.

## وين بتنحفظ البيانات
داخل رابط Claude، البيانات بتنحفظ أونلاين بقاعدة بيانات الصفحة (`claude.use("db")`)، بثلاث مجموعات: `orders` و `debts` و `contacts`.
إذا فتحت الملف برا Claude (مثلاً GitHub Pages أو من جهازك)، بيشتغل بس بيحفظ على نفس الجهاز (localStorage).

## كيف تعدّل
1. عدّل `index.html`.
2. اطلب من Claude بمشروع «تسجيل حسابات شحن TARGET COINS» ينشر النسخة الجديدة على نفس الرابط. البيانات ما بتنمسح لما ننشر نسخة جديدة.

ملاحظة: الملف ما فيه `<html>` و `<head>` لأنه Claude بيضيفهم وقت النشر.
